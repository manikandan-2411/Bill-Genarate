# Bill Generate

A simple console-based billing system developed using the C programming language.  
The program allows users to enter customer details, select products, calculate the total bill, and display the final billing information.

## Features

- Customer name and details input
- Product selection
- Quantity and price calculation
- Automatic subtotal calculation
- Total bill generation
- Simple and user-friendly console interface

## Technologies Used

- C Programming Language
- GCC Compiler
- Linux / Ubuntu
